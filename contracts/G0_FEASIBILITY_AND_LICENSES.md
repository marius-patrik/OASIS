**Decision:** neither pinned engine has been proven fundamentally infeasible by G0 source inspection. Neither is certified full-game feasible until the headless source bridge, actual renderer, native-state replay and independent multi-context tests run. Replacing either requires a separate evidence-backed architectural decision and a pinned candidate, never silent fallback.

## Mandatory independent feasibility experiments

**C / DOOM:** (C1) boot a legal pinned IWAD through original `doomgeneric_Create`; (C2) issue original controls through ticks, exercise level/thinkers/attacks and export an actual frame, assert pixel hash; (C3) run two independent world processes simultaneously, including player inputs and different maps; (C4) snapshot *full native source state* including RNG/thinkers, kill all workers and cold restore, replay deterministic sequence and compare exact game state and frame trace; (C5) prove multi-client hosting strategy with original source, without inventing OASIS mechanics. Source-image CI must build *the exact pin*; no vendored proprietary asset.

**D / Cave Story:** (D1) boot source `GameScene` in an isolated headless child with legal full scene assets; (D2) exercise original controller, tile/weapon/NPC/script/bullet updates and original native renderer to a real pixel buffer; (D3) demonstrate two independently ticking scenes/workers and multiple characters without cross-state mutation; (D4) serialize whole owned scene/player/bullet/inventory/RNG/script/camera state, kill, restore and compare gameplay and native pixel trace under identical input; (D5) validate receiver-owned typed item interactions and legal assets. The existing player-only process test is **not** evidence for D4.

**B / shared platform:** use both independent fixtures and original source workers through the *same* bounded v1 worker IPC; validate exact artifact identity, real pixels/depth, failed geometry queries and process failures. Do not change game logic to make protocol tests green.
